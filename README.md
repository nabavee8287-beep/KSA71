## 🌟 คุณสมบัติและฟังก์ชันการทำงานของระบบ (4 แถบหลัก)

### 📌 แถบที่ 1: กรอกข้อมูล KSA ของแต่ละรายวิชา
* **ค้นหาและคัดกรอง**: กรองตามรายชื่ออาจารย์ผู้สอน (คอลัมน์ E) หรือค้นหารหัสวิชา/ชื่อวิชาได้แบบ Real-time
* **หน้าต่างบันทึกข้อมูล (Popup Modal)**:
  * แสดงข้อมูล **PLO ทั้ง 7 ข้อ (PLO1 - PLO7)** พร้อมคำอธิบายสมรรถนะที่ชัดเจน
  * เมื่อติ๊กเลือก PLO ใด:
    * มีช่องให้กรอก **Knowledge (K)**: ไม่เกิน 5 ข้อ
    * มีช่องให้กรอก **Skill (S)**: ไม่เกิน 5 ข้อ
    * มีช่องให้กรอก **Attitude (A)**: ไม่เกิน 5 ข้อ
  * **คอลัมน์ G**: กรอกผลลัพธ์การเรียนรู้ระดับรายวิชาเป็นภาษาไทย (CLO Thai)
  * **คอลัมน์ H**: กรอกผลลัพธ์การเรียนรู้ระดับรายวิชาเป็นภาษาอังกฤษ (CLO English)
  * เมื่อกดบันทึก ข้อมูลจะถูกจัดรูปแบบอัตโนมัติ เช่น `PLO1: 1. ข้อแรก, 2. ข้อสอง...` บันทึกลงในคอลัมน์ I, J, K ของชีต
* **การจัดการรายวิชา**: มีปุ่มเพิ่มรายวิชาใหม่ และปุ่มลบรายวิชา

---

### 📊 แถบที่ 2: ตาราง (PLOs) กับ Knowledge/Skill/Attitude ปี 71
* **โครงสร้างตาราง 7 แถว**:
  * คอลัมน์แรกแสดงเฉพาะ **PLO1 ถึง PLO7** (1 แถวต่อ 1 PLO รวม 7 แถว)
  * คอลัมน์ถัดไปแสดงข้อมูล **Knowledge (K)**, **Skill (S)**, และ **Attitude (A)** ทั้งหมดที่อยู่ภายใต้ PLO นั้นๆ จากทุกรายวิชาที่อาจารย์กรอก
  * ข้อมูลถูกจัดเรียงเป็นข้อ ๆ อย่างเป็นระเบียบ เรียบร้อย สวยงาม
  * ไม่แสดงคอลัมน์ผู้บันทึกและวันเวลาบันทึก
* **ส่งออกข้อมูลได้ 3 รูปแบบ**:
  * 📄 **Export Word (.doc)**: รองรับการเปิดด้วย Microsoft Word พร้อมหัวเอกสารราชการและตารางจัดรูปแบบสวยงาม
  * 📑 **Export PDF / พิมพ์**: จัดหน้าพิมพ์แบบแนวนอน (Landscape) อัตโนมัติ
  * 📊 **Export CSV**: สำหรับนำไปเปิดและประมวลผลต่อใน Excel / Google Sheets

---

### 📖 แถบที่ 3: ข้อมูล KSA ของปี 66 (อ้างอิง)
* แสดงฐานข้อมูลสมรรถนะเดิมของหลักสูตรปี 2566
* แบ่งตารางออกเป็น 3 ด้าน: **ความรู้ (Knowledge)**, **ทักษะ (Skill)**, และ **เจตคติ (Attitude)**
* แสดงข้อมูลเรียงจากข้อแรกถึงข้อสุดท้ายในตารางเดียว
* มีระบบค้นหาคำสำคัญ และปุ่มคลิกคัดลอก (Copy) ข้อความไปใช้งานได้ทันที

---

### 📑 แถบที่ 4: รายวิชากับ Knowledge/ Attitude/ Skill (ภาคผนวก ค)
* ตารางตามแบบฟอร์มเอกสารหลักสูตร **ภาคผนวก ค**
* จัดกลุ่มรายวิชาตามหมวดหมู่อัตโนมัติ (เช่น **หมวดวิชาชีพครู**, **หมวดวิชาเฉพาะด้าน**)
* แมปปิ้งเครื่องหมายถูก (`✓`) กับ **PLO1 - PLO7**
* รวมข้อความ Knowledge, Skill, Attitude ของแต่ละรายวิชา
* **ส่งออกข้อมูลได้ 3 รูปแบบ**:
  * 📄 **Export Word (.doc)**: จัดหน้าตารางภาคผนวก ค
  * 📑 **Export PDF / พิมพ์**: หน้าพิมพ์ตามแบบเอกสารราชการ
  * 📊 **Export CSV**: ข้อมูลรายวิชาพร้อมเครื่องหมายเช็คถูก

## ⚡ การ Deploy และใช้งานบน Vercel (เว็บพร้อมใช้งาน)

โปรเจกต์นี้ได้รับการตั้งค่า `vercel.json` และ `package.json` ให้พร้อม Deploy บน **Vercel** แบบอัตโนมัติ:

1. เข้าไปที่ [Vercel Dashboard](https://vercel.com/new)
2. เข้าสู่ระบบด้วยบัญชี GitHub
3. ค้นหาและคลิก **Import** ที่โปรเจกต์ `nabavee8287-beep/KSA71`
4. การตั้งค่า:
   * **Framework Preset**: `Other`
   * **Root Directory**: `./`
5. คลิกปุ่ม **Deploy**
6. เว็บไซต์จะออนไลน์พร้อมใช้งานทันที (เช่น `https://ksa71.vercel.app`)

### 💡 โหมดการทำงานบน Vercel (Dual-Mode):
1. **Standalone (Browser LocalStorage)**: 
   * ใช้งานได้ทันทีแม้ไม่ได้เชื่อมต่อ Google Sheet มีข้อมูลตัวอย่างครบทั้ง 44 วิชา สามารถทดลองแก้ไข กรอก KSA เพิ่มวิชา ลบวิชาได้ โดยข้อมูลจะถูกบันทึกใน Browser ไม่สูญหายเมื่อรีเฟรช
2. **Connected (ซิงค์สองทางกับ Google Sheets)**:
   * คลิกปุ่ม **"ตั้งค่า API"** (ไอคอนคลาวด์บนขวาของหน้าเว็บ)
   * ใส่ **Google Apps Script Web App URL** แล้วกดบันทึก
   * ระบบจะอ่านและบันทึกข้อมูลสดตรงไปยัง Google Sheet ทันที!

## 📋 การ Deploy บน Google Apps Script

1. เปิดสเปรดชีต: [Google Sheet ฐานข้อมูล KSA 71](https://docs.google.com/spreadsheets/d/1jsDG5NQJ7lc1SfOS2Hz0aXpBvCwcTQYYTc39H5SKmVA/edit)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. คัดลอกโค้ดจากโปรเจกต์ไปวาง:
   * นำโค้ดจาก `Code.gs` ไปวางในไฟล์ `Code.gs`
   * นำโค้ดจาก `Index.html` ไปวางในไฟล์ `Index.html`
4. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
5. เลือกประเภท: **เว็บแอป (Web app)**
   * **คำอธิบาย**: `ระบบกรอกข้อมูล KSA 2571`
   * **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   * **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`**
6. คลิก **Deploy** และคัดลอก **URL ของเว็บแอป** นำไปส่งให้อาจารย์ใช้งาน หรือนำไปใส่ในปุ่ม "ตั้งค่า API" ของ Vercel
