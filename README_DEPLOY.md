# คู่มือการติดตั้งและใช้งานระบบกรอกข้อมูล (KSA) ปรับปรุงหลักสูตร 2571
## สาขาวิชาเทคโนโลยีดิจิทัลและสื่อสารการศึกษา คณะศึกษาศาสตร์ มหาวิทยาลัยสงขลานครินทร์

เว็บแอปพลิเคชันนี้ทำงานร่วมกับ Google Sheet:
👉 [ลิงก์ Google Sheet ฐานข้อมูล KSA 71](https://docs.google.com/spreadsheets/d/1jsDG5NQJ7lc1SfOS2Hz0aXpBvCwcTQYYTc39H5SKmVA/edit?gid=0#gid=0)

## ไฟล์สำคัญในโปรเจกต์
1. `Code.gs` : โค้ดฝั่งเซิร์ฟเวอร์ (Google Apps Script)
2. `Index.html` : โค้ดหน้าเว็บแอปพลิเคชัน (Frontend UI)
3. `local_preview.html` : ไฟล์จำลองหน้าเว็บแอปสำหรับทดสอบบนเครื่องทันที

## ขั้นตอนการติดตั้งบน Google Sheets (นำไปใช้งานจริง)

### ขั้นตอนที่ 1: เปิด Google Apps Script Editor
1. เข้าไปที่ Google Sheet ของคุณ: [เปิดสเปรดชีตที่นี่](https://docs.google.com/spreadsheets/d/1jsDG5NQJ7lc1SfOS2Hz0aXpBvCwcTQYYTc39H5SKmVA/edit?gid=0#gid=0)
2. ที่เมนูด้านบน คลิกที่ **ส่วนขยาย (Extensions)** -> **Apps Script**
3. หน้าต่างโปรแกรม Apps Script จะเปิดขึ้นมา

---

### ขั้นตอนที่ 2: วางโค้ด `Code.gs`
1. ที่แถบไฟล์ด้านซ้าย จะมีไฟล์เริ่มต้นชื่อ `Code.gs` (หรือ `รหัส.gs`)
2. ลบโค้ดเดิมออกทั้งหมด
3. เปิดไฟล์ `Code.gs` ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดไปวางแทนที่
4. กดปุ่มบันทึก (ไอคอนรูปแผ่นดิสก์ หรือกด `Ctrl + S`)

---

### ขั้นตอนที่ 3: สร้างไฟล์ `Index.html`
1. ที่แถบไฟล์ด้านซ้าย คลิกที่ปุ่มเครื่องหมายบวก **(+)** ข้างคำว่า "ไฟล์ (Files)"
2. เลือก **HTML**
3. ตั้งชื่อไฟล์ว่า `Index` (ไม่ต้องพิมพ์ `.html` ระบบจะเติมให้อัตโนมัติ) แล้วกด Enter
4. ลบโค้ดเริ่มต้นออกทั้งหมด
5. เปิดไฟล์ `Index.html` ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดไปวางแทนที่
6. กดปุ่มบันทึก (`Ctrl + S`)

---

### ขั้นตอนที่ 4: การทำให้ใช้งานได้ (Deploy เป็น Web App)
1. ที่มุมขวาบนของหน้าจอ Apps Script คลิกปุ่มสีน้ำเงิน **"การทำให้ใช้งานได้" (Deploy)** -> เลือก **"รายการทำให้ใช้งานได้ใหม่" (New deployment)**
2. คลิกที่รูปเฟือง ⚙️ ด้านซ้าย (ข้างคำว่า "เลือกประเภท") -> เลือก **"เว็บแอป" (Web app)**
3. กรอกข้อมูลการตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `ระบบกรอกข้อมูล KSA 2571 v1.0`
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me / บัญชีอีเมลของคุณ)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(สำคัญมาก: เลือกตัวเลือกนี้เพื่อให้บุคคลทั่วไปและอาจารย์สามารถเข้ากรอกข้อมูลได้โดยไม่ต้องร้องขอสิทธิ์)*
4. คลิกปุ่ม **"การทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขออนุญาตสิทธิ์ (Authorization):
   - คลิก **"ให้สิทธิ์เข้าถึง" (Review Permissions)**
   - เลือกบัญชี Google ของคุณ
   - หากขึ้นเตือน "Google ยังไม่ได้ยืนยันแอปนี้ (Google hasn't verified this app)" ให้คลิกที่ **ขั้นสูง (Advanced)** แล้วคลิก **ไปยัง... (ไม่ปลอดภัย) / Go to ... (unsafe)**
   - คลิก **"อนุญาต" (Allow)**
6. ระบบจะสร้าง **URL ของเว็บแอป (Web app URL)** เช่น:
   `https://script.google.com/macros/s/AKfycb.../exec`
7. คัดลอก URL นี้ส่งให้อาจารย์ผู้สอนและผู้เกี่ยวข้องใช้งานได้ทันที!

## ฟังก์ชันการใช้งานระบบ

### แถบที่ 1: กรอกข้อมูล KSA ของแต่ละรายวิชา
- **ดรอปดาวน์เลือกอาจารย์ผู้สอน (คอลัมน์ E)**:
  - เมื่อเลือกอาจารย์: ตารางจะคัดกรองแสดงเฉพาะรายวิชาของอาจารย์ท่านนั้น
  - เมื่อเลือก "แสดงอาจารย์ทั้งหมด": จะแสดงครบทุกวิชา (39 รายวิชา)
- **การเลือก PLO (ทั้ง 7 ข้อ)**:
  - คลิกปุ่ม **"กรอก/แก้ไข"** ในรายวิชาที่ต้องการ
  - เลือกติ๊กถูก PLO ได้หลายข้อตามต้องการ (แสดงชื่อและคำอธิบายครบทั้ง 7 ข้อ)
  - มีปุ่ม **"ลบ PLO" (x)** ออกจากรายการ หรือปุ่มล้างทั้งหมด
  - บันทึกรวมในคอลัมน์ F ของชีต
- **การกรอก CLO และ KSA**:
  - กรอก CLO ภาษาไทย (คอลัมน์ G)
  - กรอก CLO ภาษาอังกฤษ (คอลัมน์ H)
  - กรอก K : Knowledge (คอลัมน์ I)
  - กรอก S : Skill (คอลัมน์ J)
  - กรอก A : Attitude (คอลัมน์ K)
  - กดปุ่ม **"บันทึกข้อมูล KSA"** ระบบจะบันทึกลงชีต 1 และส่งข้อมูลพร้อมเวลาบันทึกไปยังชีต 2 ทันที
- **เพิ่ม/ลบรายวิชา**:
  - ปุ่ม **"เพิ่มรายวิชาใหม่"** ด้านบน
  - ปุ่มไอคอนถังขยะในตารางสำหรับลบรายวิชา

### แถบที่ 2: ตาราง (PLOs) กับ Knowledge/Skill/Attitude ปี 71
- ดึงข้อมูลจากชีต `ตาราง(PLOs)  กับ Knowledge/ Skill/ Attitude` มาแสดงอัตโนมัติ
- แสดงคอลัมน์: PLOs, K: Knowledge, S: Skill, A: Attitude, บันทึกโดย, วันและเวลาของการกรอกข้อมูล
- มีฟิลเตอร์เลือกดูเฉพาะ PLO1 - PLO7 และช่องค้นหาคำ
- ปุ่มส่งออกเป็นไฟล์ CSV (UTF-8 รองรับภาษาไทยใน Excel)

### แถบที่ 3: ข้อมูลอ้างอิง KSA ปี 66
- ดึงข้อมูลจากชีต `KSA ปึ 66`
- แสดง 3 คอลัมน์ชัดเจน: Knowledge (K01-K...), Skill (S01-S...), Attitude (A01-A...)
- ช่องค้นหาคำสำคัญรวดเร็ว
- ปุ่มคลิกคัดลอกข้อความ (Copy) เพื่อนำไปประยุกต์ใช้ในหลักสูตร 71
